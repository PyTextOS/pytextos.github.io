# PyTextOS

PyTextOS is a Linux-based command-line operating system. It uses a userspace written in Python and uses the MicroPython interpreter. It can run compiled MicroPython applications using the `.mpy` file format. It can run on 32-bit and 64-bit systems.

## Features
1. Python support via MicroPython
2. `.py` and `.mpy` applications
3. Scripting with python code
4. Support for older hardware
5. sytemd free
